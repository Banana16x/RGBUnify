2. WHAT THE SOFTWARE DOES
RGB Unify controls the lighting on hardware in your computer, including the motherboard, memory (RAM), graphics card, fans, LED strips, keyboard, mouse and other accessories. To do this it:
  a) runs with administrator rights;
  b) downloads and runs the OpenRGB engine from codeberg.org;
  c) can install the PawnIO kernel driver from github.com, which provides low-level access to the system management bus (SMBus) that RAM and motherboard lighting is attached to;
  d) can create a scheduled task that starts the Software when you sign in to Windows.

3. CLEAN UP FEATURE
The "Clean Up" page can stop, disable and uninstall other lighting software, services and drivers (for example MSI Center, Corsair iCUE, ASUS Armoury Crate). Removing that software may also remove other features it provides, such as fan control, firmware updates or macros. You decide what is removed. Creating a System Restore point first (an option on that page) is strongly recommended. You use this feature at your own risk.
